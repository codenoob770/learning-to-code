## How a lesson works

Each lesson folder has the same four files:

- `README.md` — the lesson itself. Read this first.
- `examples.py` — runnable code for every idea in the lesson. Run it, then
  change it and run it again.
- `exercises.py` — your practice. Fill in the blanks, run it, and it grades
  itself.
- `solutions.py` — worked answers with commentary. Try the exercises first.

## Running the code

You need Python 3. Check with:

```
python3 --version
```

Then, from inside a lesson folder:

```
python3 examples.py
python3 exercises.py
```
