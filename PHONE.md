# Doing this on a phone

You don't need to install anything. You need a website that runs Python for you.

## Setting it up (once)

1. Open your phone's web browser.
2. Search for **online python**.
3. Open any result that shows a box to type in and a **Run** button.
   (`programiz.com/python-programming/online-compiler` and `onlinegdb.com`
   both work fine. Any of them will do.)
4. Bookmark it. That's your setup, done.

There'll be a box with some code already in it. Delete whatever is in there,
type or paste your own code in, and tap **Run**. The answer appears underneath
or off to the side.

## How the lessons work on a phone

The lesson files in this repo are meant to be run on a computer. On a phone,
do it this way instead:

- Ask Claude for the next lesson. It'll paste the code straight into the chat.
- Press and hold on the code to copy it.
- Switch to your browser, paste it in, tap **Run**.
- Switch back and tell Claude what it printed.

Same learning, no file juggling.

## Two annoyances, and what to do about them

**Typing `"` and `:` and `(` is slow.** Your keyboard hides them behind the
`123` key. That's normal and everyone hates it. Copy-paste as much as you can.

**Spacing matters in Python, and phones are bad at it.** Lines inside an `if`
or a `for` have to be pushed in by 4 spaces. If you're typing by hand, tap the
spacebar 4 times. If you paste, the spacing comes along with it - which is
another reason to paste.

## The practice checker

`python3 check.py` needs a computer, so it won't run on your phone. Instead,
just paste what your code printed into the chat and Claude will tell you if
it's right.

## When you get to a computer

Everything gets easier. Read the main README then, and use the lesson files
properly. Nothing you learn on the phone goes to waste.
